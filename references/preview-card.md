# 预习卡规则

预习卡的作用是让学员对当天话题有基本语料准备，不是布置词块输出任务。

## 固定结构

1. 今日话题。
2. 今天大概会聊什么。
3. 6—10个关键词及中文意思。
4. 从所选话题本地语料中选取5个词块、中文意思和每个词块1个例句；话题文件保存更多表达时，优先选贴合学员需求的5个。无需连接Notion。
5. 3—5道可能遇到的引导问题，只用于帮助学员预判内容。
6. 一条容易出错或需要注意的表达说明。
7. 开始和结束指令。

结尾固定使用：

```text
这些词块只是预习参考，不需要全部使用，也不用背下来。
准备好后回复“开始”；想结束时回复“复盘”。
```

## 呈现原则

- 不让学员选择“今日目标词块”。
- 不设置“必须使用几个词块”的挑战。
- 不展示完整示范对话，避免学员直接背答案。
- 五个词块全部展示，但每个只保留一个代表性例句。
- 控制中文解释长度，让学员能够在几分钟内看完。
