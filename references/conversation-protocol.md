# 对话流程

## 状态

```text
选择话题 → 预习卡 → 等待开始 → 引导问答
                       ↕
                    轻量纠错
                       ↓
                  结束 → 复盘
```

不得跳过“等待开始”。进入复盘后不得继续抛出新问题。

## 每轮顺序

1. 用自然日语回应学员刚才表达的意思。
2. 如果存在影响理解、反复出现或特别值得处理的问题，只修正一个。
3. 顺着内容提出一个自然追问。

示例：

```text
なるほど。AIを仕事の下調べに使っているんですね。

小调整：
「AIで調べてもらう」→「AIに調べてもらう」

AIに任せず、自分で確認していることもありますか？
```

不要在每轮回答后都显示选项。只有需要转换角度、学员卡住或主动要求时，才显示：

```text
接下来想聊哪个方向？
1. AIで一番助かった経験
2. AIに任せたくないこと
3. AIの進化への不安
```

## 引导问题的使用

- 第一道问题使用话题文件中的开场问题。
- 后续优先顺着学员刚才说的内容追问。
- 如果当前内容难以继续，再从话题文件的引导问题中选择合适角度。
- 一次只问一道问题，不机械地从题库顶部问到底。
- 一次训练重点完成3道主要问题；自然追问不必全部计为主要问题。

## 逐级提示

学员卡住时只提供当前所需的最低一级帮助，然后等待重新尝试：

1. 换一种更容易理解的日语重新提问。
2. 用中文说明可以回答的意思或方向，但不给日语答案。
3. 给日语关键词或半句框架。
4. 给完整自然示范，让学员模仿或改编。

记录该问题使用过的最高提示等级。看完整示范后复述，不算独立回答。

## 轻量纠错

只在以下情况打断：

- 错误影响理解；
- 同类错误反复出现；
- 这个问题会明显影响学员之后继续表达。

即时纠错优先使用：

```text
学员原句 → 最小修正
```

解释最多一两句，然后马上回到对话。其余语法和自然度问题留到复盘。

## 结束信号

“结束”“复盘”“今日はここまで”等明确表示停止训练的内容，都直接触发复盘。确认一次即可，不再要求学员补答最后一道题。
