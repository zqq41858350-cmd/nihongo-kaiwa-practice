# 日语口语陪练 Skill

围绕13个话题，完成「预习 → 引导问答 → 逐级提示 → 轻量纠错 → 结构化复盘 → 重答复习」。适合有日语基础、想练习主动表达的学员。

## 01｜安装与使用

### 支持从 GitHub 安装 Skill 的 AI 工具

把仓库链接交给工具，并发送：

```text
请从此 GitHub 仓库安装 nihongo-kaiwa-practice Skill。
请完整读取 SKILL.md，并同时安装 curriculum、references 和 scripts 等支持文件。
安装后显示主菜单。
https://github.com/zqq41858350-cmd/nihongo-kaiwa-practice
```

是否能直接安装由工具决定；仅提供链接不代表工具会自动加载全部文件。

### 支持上传 Skill 压缩包的 AI 工具

在 GitHub 点击 **Code → Download ZIP**，解压后按工具要求导入完整 Skill 文件夹。文件夹中应直接包含 `SKILL.md`。

### 只支持项目知识库的 AI 工具

下载并解压，将 `SKILL.md` 和 `curriculum`、`references` 中的文件上传到知识库，设置指令：

```text
请按照 SKILL.md 开展日语口语训练。
先显示主菜单，按需读取所选话题和规则文件；预习后等待我说“开始”，再进行问答。
```

以上素材适用于 Mac 和 Windows。预习、问答和聊天复盘无需运行脚本；本地记录归档需要 Python 3 和工具的文件执行能力。

## 02｜练习流程

唤起已安装的 Skill（如工具支持，可用 `$nihongo-kaiwa-practice`）→ 选话题 → 看预习卡 → 回复“开始” → 用日语回答 → 回复“复盘”。

卡住时可以说“给我提示”，想换问题可以说“换问题”。预习词块仅作参考，不要求强制使用。

复盘包括语法最小修正、逐题原回答与自然表达、内容与结构评价，以及先展示推荐结构、再合并的个人日语语料。

## 03｜13个话题

1. AIについて｜AI
2. これからの計画｜未来计划
3. 買ってよかった物・失敗した物｜购物体验
4. もっと早く知りたかったこと｜早知道就好了
5. SNSとの関係｜社交媒体
6. グルメ自慢大会｜美食分享
7. おすすめのアニメ・ドラマ・本・映画・ポッドキャスト｜作品推荐
8. 故郷の話｜家乡
9. 勇気と怖さ｜勇气与害怕
10. 仕事の話｜工作
11. 学生時代の話｜学生时代
12. 人生最高の瞬間｜人生最棒的瞬间
13. 友情の話｜友情

话题已内置，练习时不需要连接 Notion。

## 04｜项目文件

- `SKILL.md`：入口规则与话题菜单。
- `curriculum/topics/`：13个话题的预习语料与引导问题。
- `references/`：预习、对话、复盘及成长记录规则。
- `scripts/records.py`：本地训练记录归档与查询。
- `agents/openai.yaml`：支持此格式的工具使用的界面元数据，其他平台可忽略。

## 05｜记录与成长

当前提供聊天复盘和经授权的本地记录保存，不提供网页复习台。无法保存文件的平台不会自动持久保存记录。

建议次日、第3天、第7天重答；第1天和第21天在相近条件下比较独立回答、提示依赖、内容完整度和高频错误。没有音频证据时不评价发音。

个人练习记录应保存在仓库外，请勿提交到公开项目。
